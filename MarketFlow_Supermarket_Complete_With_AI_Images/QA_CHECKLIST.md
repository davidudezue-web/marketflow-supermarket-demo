# MarketFlow user acceptance checklist

- [ ] Home page loads at desktop and mobile widths.
- [ ] Shop shows twenty catalogue items with correct sample prices.
- [ ] Department, search and sort filters work.
- [ ] A product can be added to a basket; quantities respect current stock.
- [ ] Placing a demo order creates a browser-only order reference.
- [ ] Operations view in the **same browser** shows that order and total.
- [ ] Product stock decreases by the sold quantity.
- [ ] POS entry creates a second demo sale and decrements stock.
- [ ] Restock adds quantity, and waste subtracts quantity and creates an audit line.
- [ ] Orders and inventory export CSV files with the correct columns.
- [ ] Reset clears local order, waste, cart and stock changes.
- [ ] PDF guides, CSV catalogue and JSON scenario reference download.
- [ ] Email, WhatsApp, phone and LinkedIn links point to the stated consultant contacts.
- [ ] No real payment, shared cloud database, authenticated admin or genuine client data is claimed.
